# Deep SVDD Examples

The examples are separated by encoder type. All notebooks use the
PySelectInf CPU backends and do not import the external `padi` package.

```text
deepsvdd/
├── README.md
├── dnn/
│   ├── network.py
│   ├── train.ipynb
│   ├── compute_pvalue.ipynb
│   ├── validate_pvalue.ipynb
│   └── weights/
│       └── mlp_encoder.pth        (generated by train.ipynb)
└── cnn/
    ├── network.py
    ├── train.ipynb
    ├── compute_pvalue.ipynb
    ├── validate_pvalue.ipynb
    └── weights/
        └── patch_network.pth      (generated by train.ipynb)
```

## DNN

The `dnn/` directory contains a tabular Deep SVDD pipeline.

**Encoder architecture** (`network.py`):

```text
Linear → BatchNorm1d → LeakyReLU → Linear
```

All Linear layers use `bias=False`; BatchNorm1d uses `affine=False`.

**Workflow:**

1. **`train.ipynb`**: Generate synthetic normal tabular data (N(0,1)) →
   initialise center **c** → Deep SVDD train (minimise ‖f(x) − c‖²) →
   compute R² → save `weights/mlp_encoder.pth`.

2. **`compute_pvalue.ipynb`**: Load trained MLP → generate one anomalous
   test sample + normal reference samples → build `DeepSVDDAD(network_type="dnn")`
   Pipeline → compute selective p-value.

3. **`validate_pvalue.ipynb`**: Repeatedly sample normal test data → collect
   p-values from false detections → run KS test against Uniform(0, 1) to
   validate the selective inference procedure.

## CNN

The `cnn/` directory contains an image-patch Deep SVDD pipeline.

**Encoder architecture** (`network.py`):

```text
Conv2d → BatchNorm2d → LeakyReLU → MaxPool2d → Conv2d → BatchNorm2d → LeakyReLU → MaxPool2d → Linear
```

All Conv2d and Linear layers use `bias=False`; BatchNorm2d uses `affine=False`.

**Workflow:**

1. **`train.ipynb`**: Generate synthetic 300×300 normal images → extract 30×30
   patches → initialise center **c** → Deep SVDD train (minimise ‖f(x) − c‖²) →
   compute R² → save `weights/patch_network.pth`.

2. **`compute_pvalue.ipynb`**: Load trained PatchNetwork → generate one
   anomalous test patch + normal reference patches → build
   `DeepSVDDAD(network_type="cnn")` Pipeline → compute selective p-value.

3. **`validate_pvalue.ipynb`**: Repeatedly sample normal test patches → collect
   p-values from false detections → run KS test against Uniform(0, 1) to
   validate the selective inference procedure.
